# IPTV TV

Android/Android TV приложение для просмотра IPTV. Приложение загружает M3U,
воспроизводит HLS через Media3, управляется пультом и обновляется через GitHub
Releases.

## Архитектура

- `domain` — модели, контракты репозиториев и сценарии использования;
- `data` — текущий хардкод каналов и клиент GitHub Releases;
- `presentation` — Compose UI, состояние экрана и Media3 ExoPlayer.

## Настройка GitHub-обновлений

1. Создайте публичный GitHub-репозиторий.
2. В `app/build.gradle.kts` укажите `GITHUB_REPOSITORY` в формате
   `owner/repository`.
3. Создайте один release-keystore и никогда не меняйте его для последующих
   обновлений.
4. Добавьте в GitHub Actions Secrets:
   `IPTV_KEYSTORE_BASE64`, `IPTV_KEYSTORE_PASSWORD`, `IPTV_KEY_ALIAS`,
   `IPTV_KEY_PASSWORD`.
5. Перед выпуском увеличьте `versionCode` и `versionName`, затем создайте тег:

   ```shell
   git tag v0.2.0
   git push origin v0.2.0
   ```

Workflow соберёт подписанный `IPTV-TV.apk` и прикрепит его к GitHub Release.
При следующем запуске приложение сравнит версию release с установленной,
предложит обновление, скачает APK и откроет системное окно установки.

> Первый APK и все обновления должны быть подписаны одним ключом. Сам ключ в
> Git добавлять нельзя.

## Управление

- `Menu` — открыть настройки ссылки на поток;
- `←` — открыть список каналов;
- `↑` / `↓` — плавно выбрать категорию или канал;
- `OK` / `→` — открыть категорию;
- `OK` — включить выбранный канал;
- `Back` / `←` — вернуться к категориям или закрыть список.

Ссылка на поток хранится только в приватных данных установленного приложения.
Обычное обновление APK сохраняет её. Удаление приложения или очистка его данных
удалит настройку.

Список каналов кэшируется на устройстве для быстрого повторного запуска.
